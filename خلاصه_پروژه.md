## 🔧 Customization

### Changing Parameters
Edit `config.py`:

```python
# Wavelet
WAVELET_CONFIG = {
    'dwt_wavelet': 'db4',        # db1, db2, ..., db10
    'decomposition_level': 3,     # 2, 3, 4, 5
}

# Weights
ASSESSMENT_CONFIG = {
    'stat_alpha': 1.0,           # 0.5 to 2.0
    'stat_beta': 0.5,            # 0.1 to 1.0
    'stat_gamma': 0.3,           # 0.1 to 1.0
}
```

### Adding New Dataset
1. Create file in `data/loaders/`
2. Inherit from `BaseDataLoader`
3. Implement `load()` method

Example:
```python
from . import BaseDataLoader

class MyDatasetLoader(BaseDataLoader):
    def load(self):
        # Loading code
        return data
```

### Adding New Method
1. Create file in `methods/`
2. Implement `assess_single()` and `batch_assess()`
