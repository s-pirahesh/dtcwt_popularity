# Content Popularity Prediction using Multi-Scale Frequency Decomposition

A comprehensive framework for measuring and predicting content popularity in distributed systems using wavelet-based signal processing and graph analysis.

## Introduction

This project implements advanced popularity measurement methods by combining the following:
- **Wavelet Transforms**: DWT and Dual-Tree Complex Wavelet Transform (DTCWT)
- **Graph Signal Processing**: Content relationship graphs with spectral analysis
- **Statistical Methods**: ARMA, EWMA and traditional caching policies (LRU, LFU)
- **Hybrid Approaches**: Combining multiple methods for enhanced prediction

## Features

- **Multi-Dataset Support**: MovieLens, Youku, YouTube
- **Temporal Flexibility**: Daily, hourly, minute-based or custom intervals
- **Two Evaluation Modes**:
  - Standard: Full in-memory assessment
  - Incremental: Memory-efficient assessment, fault-resistant
- **Comprehensive Metrics**: Spearman correlation, Kendall tau, stratified analysis
- **Parallel Processing**: Multi-core support for faster assessment
- **Rich Visualization**: Performance comparison charts and statistics

**Granularity Options:**

## Assessment

### Standard Mode

Full in-memory assessment with all features:

```bash
python experiments/run_popularity_assessment.py DATASET [OPTIONS]
```

**Arguments:**

- `DATASET`: Dataset name (`movielens`, `youtube07`, `youku`)
- `--num-items N`: Number of items to assess (default: all)
- `--start-date YYYY-MM-DD`: Assessment start date
- `--end-date YYYY-MM-DD`: Assessment end date
- `--window-size N`: Training window size in time units (default: 30)
- `--horizon N`: Prediction horizon (deprecated, not used in assessment mode)
- `--methods M1 M2 ...`: Specific methods to assess (default: all)
- `--item-selection {top,random,stratified}`: Item selection strategy (default: top)
- `--cores N`: Number of CPU cores to use (default: all)
- `--format {csv,parquet}`: Output format (default: csv)
- `--data-path PATH`: Custom data file path
- `--quiet`: Suppress verbose output

**Available Methods:**
- `AF`: Access Frequency (baseline)
- `LRU`: Least Recently Used
- `LFU`: Least Frequently Used
- `EWMA`: Exponentially Weighted Moving Average
- `Statistical`: ARMA-based statistical model
- `DWT+AF`: Discrete Wavelet Transform + Access Frequency
- `DTCWT+AF`: Dual-Tree Complex Wavelet Transform + Access Frequency
- `Hybrid V3.0`: Wavelet-statistical hybrid
- `Hybrid V3.1`: Advanced hybrid with graph features

**Examples:**

Assess top 1000 items for 3 months:
```bash
python experiments/run_popularity_assessment.py movielens \
  --num-items 1000 \
  --start-date 2023-06-01 \
  --end-date 2023-08-31
```

Assess specific methods only:
```bash
python experiments/run_popularity_assessment.py movielens \
  --num-items 500 \
  --methods AF LRU LFU DTCWT+AF \
  --cores 4
```

Random sampling with custom time range:
```bash
python experiments/run_popularity_assessment.py movielens \
  --num-items 200 \
  --item-selection random \
  --start-date 2023-07-01 \
  --end-date 2023-07-31
```

### Incremental Mode

Memory-efficient assessment with continuous storage:

```bash
python experiments/run_popularity_assessment.py DATASET --incremental [OPTIONS]
```

**Advantages:**
- Low memory consumption (<200 MB)
- Fault-resistant: Results continuously saved to SQLite database
- Progress tracking: Resume from last saved state
- Suitable for large-scale assessments

**Example:**

```bash
python experiments/run_popularity_assessment.py movielens \
  --num-items 5000 \
  --start-date 2023-01-01 \
  --end-date 2023-12-31 \
  --incremental \
  --cores 8
```

### Temporal Granularity

Framework automatically manages different temporal granularities:

**Daily (MovieLens):**
```bash
# Window size = 30 days, evaluate 92 time steps for 92-day period
python experiments/run_popularity_assessment.py movielens \
  --window-size 30
```

**5-Minute (Youku):**
```bash
# Window size = 288 steps (24 hours), evaluate video-level popularity
python experiments/run_popularity_assessment.py youku \
  --window-size 288
```

**Weekly:**
```bash
# First convert data to weekly, then window size = 8 weeks
python data/convert_movielens.py --granularity weekly
python experiments/run_popularity_assessment.py movielens \
  --window-size 8
```

## Troubleshooting

### Memory Issues

Use incremental mode for large assessments:
```bash
python experiments/run_popularity_assessment.py movielens \
  --num-items 10000 \
  --incremental
```

### Import Errors

Install missing dependencies:
```bash
pip install pywt dtcwt scipy
```

### Data Format Issues

Ensure your data has correct columns and types:
```python
import pandas as pd
df = pd.read_csv('your_data.csv')
df['timestamp'] = pd.to_datetime(df['timestamp'])
df['count'] = df['count'].astype(int)
```

### Temporal Granularity Mismatch

Ensure dataset and configuration match:
- Daily data → `time_granularity='daily'`
- Hourly data → `time_granularity='hourly'`
- 5-minute data → `time_granularity='custom'`, `slot_duration_minutes=5`

## Performance Optimization Tips

1. **Use Parallel Processing:**
   ```bash
   --cores 8  # Use 8 CPU cores
   ```

2. **Select Fewer Methods:**
   ```bash
   --methods AF DTCWT+AF  # Only required methods
   ```

3. **Use Incremental Mode for Large Datasets:**
   ```bash
   --incremental  # Memory consumption <200 MB
   ```

4. **Optimize Window Size:**
   - Smaller windows = faster but less accurate
   - Larger windows = slower but more accurate
